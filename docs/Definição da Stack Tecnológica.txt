# Definição da Stack Tecnológica

## Linguagens Utilizadas
- **JavaScript** → Desenvolvimento da extensão do navegador e funcionalidades do frontend.
- **Python** → Desenvolvimento do backend e regras de negócio do sistema web.
- **HTML5** → Estrutura das páginas web e interface da extensão.
- **CSS3** → Estilização e responsividade da aplicação.

---

## Frameworks e Bibliotecas

### Frontend
  - Criação da interface do sistema web.
  - Componentização da dashboard e telas de estudo.
  - Melhor experiência do usuário e manutenção facilitada.

- **Tailwind**
  - Estilização rápida e responsiva.
  - Compatibilidade com diferentes dispositivos.

---

### Backend
- **Django**
  - Framework robusto em Python.
  - Integração simples com banco de dados.
  - Facilidade de desenvolvimento para MVP.
  - ORM para manipulação do banco de dados.
  - Facilita operações CRUD dos usuários, legendas e flashcards.

---

### Banco de Dados
- **MySQL**
  - Banco completo.
  - Fácil configuração e integração com Django.

---

### Extensão de Navegador
- **Chrome Extension API**
  - Captura automática das legendas do YouTube.
  - Comunicação entre navegador e sistema web.

---

## Ferramentas de Desenvolvimento
- **Git e GitHub**
  - Controle de versão e colaboração entre a equipe.

- **Visual Studio Code**
  - IDE principal para desenvolvimento.

- **Postman**
  - Testes da API REST.

---

## Hospedagem
- **Deploy rápido e gratuito para MVP
  - Hostgator ou Hostinger para projeto final

---

## Requisitos Não Funcionais Atendidos

### Desempenho
- Django e MySQL garantem rapidez no processamento do MVP.

### Escalabilidade
- Django permitem futura migração para arquiteturas maiores.

### Usabilidade
- Interface responsiva com Tailwind.
- Navegação simples e intuitiva.

### Manutenibilidade
- Separação entre frontend, backend e extensão.
- Uso de GitHub para versionamento.

### Compatibilidade
- Sistema acessível via navegador moderno.
- Extensão compatível com Google Chrome.

### Segurança
- Sistema de autenticação para login de usuários.
- Proteção básica de rotas e dados.
